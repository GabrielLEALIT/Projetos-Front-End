🚀 Projetos no Repositório
🏋️‍♂️ 1. Página de Academia
Descrição: Uma landing page completa e moderna desenvolvida para uma academia, focada em apresentação de serviços, planos e captura de clientes.

Tecnologias: HTML5, CSS3, JavaScript.

Destaques: Design responsivo, navegação fluida e interface intuitiva.

🧮 2. Calculadora
Descrição: Uma aplicação funcional de calculadora desenvolvida para executar operações matemáticas com facilidade.

Tecnologias: HTML5, CSS3, JavaScript.

Destaques: Manipulação do DOM, tratamento de eventos e interface amigável.
